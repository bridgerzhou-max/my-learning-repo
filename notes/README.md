# notes 目录

每周一篇，文件名用 `YYYY-Www.md`（ISO 周编号），例如 `2026-W45.md` 是 2026 年第 45 周。

## 怎么写

复制 [`_模板.md`](_模板.md) 改名，按五段填：

1. **这周学了什么** —— 知识点，一行一个
2. **动手做了什么** —— 代码在哪个文件夹、跑没跑通
3. **卡住的地方** —— 现象 / 我先试了什么 / 最后怎么解决的
4. **一个想明白的点** —— 说不清楚，说明还没懂
5. **下周计划** —— 两三条就够

第 3 段最有用：**报错原文要贴进去**，那是以后能搜到自己的唯一线索。
