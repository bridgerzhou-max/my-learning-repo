# 第 45 周（2026-11-02 ~ 2026-11-08）

## 这周学了什么

- Markdown 的基本写法：标题用 `#`，列表用 `-`，代码用三个反引号包起来
- Git 的三个概念：工作区、暂存区、本地仓库；`add` 是放进暂存区，`commit` 才是存进本地仓库
- C 语言的 `printf` 和转义字符 `\n`

## 动手做了什么

- 代码在：`code/01-hello-world/main.c`
- 跑通了吗：跑通了，输出是 `Hello, Xiangnan University!`

## 卡住的地方

- **现象**：第一次 `git push` 报错 `Authentication failed`
- **我先试了什么**：把 GitHub 密码重新输了一遍，还是不行
- **最后怎么解决的**：查了才知道 GitHub 从 2021 年起不让用密码推送，要用
  Personal Access Token；换成 GitHub Desktop 登录后直接就好

## 一个想明白的点

提交（commit）不是"保存文件"，而是给这个时间点的代码拍一张照片。
所以提交信息要写清楚此刻做了什么，不然回头翻照片谁也不知道那是啥。
