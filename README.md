# 学习仓库

这个仓库记录我从大一开始的学习过程：课程练习、每周笔记，以及做过的每一个小东西。
我给自己定的规矩很简单——**每周至少一次提交，学了什么就留下什么**。

## 目录结构

```
my-learning-repo/
├── README.md          就是你现在看的这个
├── 上手清单.md         第一次用要做的几件事（做完可以删）
├── code/              课程练习与小项目，一个项目一个文件夹
└── notes/             每周一篇学习笔记，文件名用「年-第几周」
```

## 我的节奏

| 时间 | 做什么 |
| --- | --- |
| 每学完一节 | 把当天的代码或理解写进 `notes/` 或 `code/` |
| 每周日晚 | 补完整周笔记，提交一次 |
| 每月底 | 回头翻一遍，把之前的错误理解改掉 |
