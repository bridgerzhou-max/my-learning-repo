## 这个仓库是什么

计算机科学与技术专业 2026 级本科生，从大一开学起在本地记录学习过程。仓库只做一件事：
**把学过的东西留成可以回看的痕迹**，而不是学完就忘、期末再从头捡一遍。

- **`code/`** —— 课上的练习、课后自己写的小程序，一个项目一个文件夹
- **`notes/`** —— 每周一篇学习笔记，写清楚「学了什么 / 卡在哪 / 怎么解决的」

不是作品集，也没有炫技的内容。写得糙的地方就是当时真实的理解水平，
以后回头改，本身就是一种进步。

## 目录结构

```text
my-learning-repo/
├── code/                 课程练习与小项目
│   └── 01-hello-world/   第一个 C 程序
├── notes/                每周一篇学习笔记
│   ├── _模板.md           每周照这个写
│   └── 2026-W45.md       第 45 周
├── 上手清单.md            第一次配置环境的步骤（已完成，留个底）
└── README.md
```

## 每周怎么用

| 时间 | 做什么 |
| --- | --- |
| 每学完一节 | 代码进 `code/`，结论进 `notes/` |
| 每周日晚 | 补完整周笔记，提交一次 |
| 每月底 | 回翻旧笔记，把当时理解错的地方改掉 |

提交信息写人话，例如 `第46周笔记：弄懂了指针和数组的区别`。
不写 `update`、`修改`、`提交` —— 三个月后自己都看不懂。

## 笔记与代码的写法

- 笔记放在 `notes/YYYY-Www.md`，照 [`_模板.md`](notes/_模板.md) 的五段式写，说明见 [notes/README.md](notes/README.md)
- 代码放在 `code/序号-简短英文/`，每个文件夹带自己的 README，说明见 [code/README.md](code/README.md)
